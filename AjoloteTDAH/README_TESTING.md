# 🦎 AjoloteTDAH - Guía de Testing

## 📱 Cómo Probar la App

### Opción 1: Expo Go (Más Fácil)
1. **Descarga Expo Go** en tu dispositivo:
   - iOS: [App Store](https://apps.apple.com/app/expo-go/id982107779)
   - Android: [Google Play](https://play.google.com/store/apps/details?id=host.exp.exponent)

2. **Escanea el QR** que aparece en la terminal o navegador

3. **¡Listo!** La app se abrirá en tu dispositivo

### Opción 2: Build de Desarrollo
- Para usuarios más técnicos o testing más profundo
- Instrucciones en la sección "Build" más abajo

## 🎯 Qué Probar

### Flujo Principal:
- [ ] Pantalla de inicio y onboarding
- [ ] Registro de usuario
- [ ] Crear y completar tareas
- [ ] Ver evolución del ajolote
- [ ] Comprar accesorios en recompensas
- [ ] Personalizar perfil

### Funcionalidades Específicas:
- [ ] Modo oscuro/claro
- [ ] Animaciones y transiciones
- [ ] Persistencia de datos
- [ ] Navegación entre pantallas

## 📝 Feedback a Recopilar

### UX/UI:
- ¿Es fácil de usar?
- ¿Las animaciones son fluidas?
- ¿Los colores son agradables?
- ¿Hay algo confuso en la navegación?

### Funcionalidad:
- ¿Las tareas se guardan correctamente?
- ¿El sistema de puntos funciona bien?
- ¿La gamificación es motivadora?
- ¿Hay bugs o errores?

### Valor:
- ¿Te ayudaría con tu productividad?
- ¿Te gustaría usar esta app regularmente?
- ¿Qué funcionalidades agregarías?
- ¿Qué cambiarías?

## 🐛 Reportar Problemas

Si encuentras algún problema:
1. **Screenshot** del error
2. **Descripción** de qué estabas haciendo
3. **Dispositivo** y sistema operativo
4. **Pasos** para reproducir el error

## 📊 Métricas a Observar

- Tiempo en cada pantalla
- Tareas completadas vs abandonadas
- Uso de recompensas
- Engagement con el ajolote
- Frecuencia de uso
